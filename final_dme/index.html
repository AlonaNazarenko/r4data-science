Transliteration

Since one of the databases is provided in English, I first transliterate the surnames into Ukrainian using the transliterate library.
In addition, I perform transliteration into Russian, as the second database is recorded in the language used at the time — Old Ukrainian. In it, some surnames are documented with letters characteristic of the Russian alphabet.

After that, I split the data into columns with surnames for further processing.

people_1897[['surname_uk', 'name_uk', 'patronymic_uk']] = people_1897.full_name.str.split(' ', n=2, expand=True)\
  .map(lambda x: translit(x, 'uk') if pd.notnull(x) else x)   
people_1897['surname_ru'] = people_1897.full_name.str.split(' ', n=1)\
    .str[0].map(lambda x: translit(x, 'ru') if pd.notnull(x) else x)

Extracting the Root of Surnames in the 1897 Census

To count all people with the same surname in 1897, where surnames differed formally (due to declension), I try to extract the root of the word by removing the most common and grammatically similar (transliterated) suffixes and endings.

This is done in two stages:
1. Using regular expressions.
2. Through additional processing of individual cases.

surnames = list((set(people_1897.surname_ru.unique()) & set(people_1778.surname.unique())) \

I count the number of people with each surname separately for 1778 and 1897.
To do this, I filter the data by the list of surnames or surname roots, group by surname, and count the number of unique individuals.

After counting for each year, I add a group column indicating the year, and combine both results into a single dataframe.

I also calculate the difference between the number of people in 1897 and 1778 and add it to the combined dataframe.

amount_surnames_1778 = people_1778[people_1778.surname.isin(surnames)]\

Data Preparation

Since the 1778 data does not have a separate column indicating sex, I created a new sex column based on one of the existing columns that allows determining whether a person is male or female. This column will be used for further analysis.

people_1778['sex'] = np.where(
    people_1778['m_num_unique'].notna(), 'm', 'f'
)

In addition, the 1897 data has an issue with accurately determining age, as some records contain values like 6 month, 2 week, 1.5, etc.

Since I will be creating an age-sex pyramid with 5-year age intervals, the exact number of days or months for a child — 6 months or 2 weeks — is not significant; in any case, it is less than one year. Therefore, I assign a value of 0 to such records.

To avoid ambiguities with incomplete numeric values (e.g., 1.5), I round all age values to whole numbers and use the Int8 data type. This is possible because the dataset does not include people older than 127 years — i.e., there are no cases exceeding the limits of this data type.

people_1897['age'] = np.where(
    people_1897['age'].astype(str).str.contains('month|week|day|less'),
    0,
    pd.to_numeric(people_1897['age'], errors='coerce').round().astype('Int8')
)

Since I will be creating two pyramids, I don’t want to duplicate code with the same structure for each of them. Therefore, I decided to extract the repeated logic into a separate function for plotting the graph.

def Population_Pyramid_graph(df : pd.DataFrame, year):
    base = alt.Chart(df)
    
    color_scale = alt.Scale(domain=['m', 'f'],
                            range=['#1f77b4', '#e377c2'])
    
    left = base.transform_filter(
        alt.datum.sex == 'f'
    ).mark_bar().encode(
        y=alt.Y('age:Q', 
                axis=None, 
                bin=alt.Bin(step=5),
               scale=alt.Scale(domain=(0, 90))
               ),
        x=alt.X('count(ID_person):Q',
                title='population',
                sort=alt.SortOrder('descending'),
                scale=alt.Scale(domain=(0, 170)),
               ),
        color=alt.Color('sex:N', scale=color_scale, 
                        legend=None
                       ),
        tooltip = alt.Tooltip(['count(ID_person)'])
    ).properties(
        title=alt.Title('Female', font=font_text, fontSize = 16),
        height = 360,
        width=200
    )+ alt.Chart(pd.DataFrame({'text': [str(year)]})).mark_text(
    x=50,
    y=30,
    fontSize=20,
        font=font_text
).encode(
    text='text:N'
)

    bins = np.arange(90, -5, -5)
    labels = [f"{bins[i+1]}-{bins[i]}" for i in range(len(bins)-1)]
    interval_df = pd.DataFrame({
        'Range': labels
    })
    
    middle = alt.Chart(interval_df).mark_text().encode(
        y=alt.Y('Range:N', axis=None, sort=labels),
        text='Range'
    ).properties(width=40)
    
    right = base.transform_filter(
        alt.datum.sex == 'm'
    ).encode(
        y=alt.Y(
            'age:Q', 
            bin=alt.Bin(step=5), 
                axis=None
               ),
        x=alt.X(
            'count(ID_person):Q',
            title='population', 
            scale=alt.Scale(domain=(0, 130)), 
        ),
        tooltip = alt.Tooltip(['count(ID_person)']),
        color=alt.Color('sex:N', scale=color_scale, legend=None)
    ).mark_bar().properties(
        title = alt.Title('Male', font=font_text, fontSize = 16),
        height = 360,
        width=200
    )
    
    return alt.concat(left, middle, right, spacing=5)

Categorization of Educational Institutions

Since the data contains 41 unique names of educational institutions, for better readability, I categorize these names into 7 generalized groups:

  • Zemstvo school
  • Rural school
  • Home education
  • City school
  • Church education (education at the church)
  • Military education (education in the regiment)
  • Other — all other cases that do not fall into any of the previous categories

To do this, I use regular expressions to automatically identify keywords and phrases characteristic of each category.

condition = [
    education_status.education.str.contains(r'\bzemsk(?:oe|om|aya)', case=False),
    education_status.education.str.contains(r"\b(?:sel's?k(?:[aoe]e?|aya)|sel'skoj|rural)\b", case=False),
    education_status.education.str.contains(r'\b(?:home|doma)\b', case=False),
    education_status.education.str.contains(r'\bgorod(?:skoe|skom)\b', case=False),
    education_status.education.str.contains(r'\b(?:cerkovno[- ]prikhodskaya|u prichetnika|seminariya|umanskoe|Novgorod-Severskaya)\b', case=False),
    education_status.education.str.contains(r'\b(?:v polku)\b', case=False),
]

education_type = [
    'Zemstvo school',
    'Rural school',
    'Home education',
    'City school',
    'Church school',
    'Military education'
]

education_status['category'] = np.select(condition, education_type, default='Others')

Simplifying Social Statuses

In addition to the main analysis, I also reduced the number of unique social statuses, as some of them have similar social or economic positions and can be grouped into generalized categories.

The grouping is done as follows:

  • Peasant:
    • peasant-owner and state peasant were combined, as both groups belonged to the rural population that owned or worked the land, regardless of the form of ownership.
  • Noble:
    • nobles and imenuyushchijsya dvoryanin share a privileged social status, placing them in the noble class.

This grouping helps avoid excessive detail, reduces the number of categories, and better represents overall social trends in the visualization.

education_status.social_status = education_status.social_status.map({
    'cossack': 'Cossack',
